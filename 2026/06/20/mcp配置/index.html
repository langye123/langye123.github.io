npm install -g supergateway

supergateway 是一个专为 MCP 服务器设计的远程调试与集成工具。将基于标准输入输出（stdio）的 MCP 服务器，转换为通过 SSE（Server-Sent Events） 或 WebSocket 访问的服务
本地开发了一个 MCP 服务器，但您的客户端（如某些网页端或远程客户端）不支持 stdio 协议，只支持 SSE。这时就可以用 supergateway 作为一个中间层，把本地的 stdio 服务暴露成 SSE 服务，从而方便远程调试和客户端集成。
